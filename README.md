# 中国象棋

这是一个面向 Windows x64 的本地中国象棋软件。棋盘、残局编辑器和规则判断在本机运行，棋力由官方 Pikafish 2026-09-06 引擎提供。

## 启动

请先完整解压压缩包，不要直接在压缩包预览窗口中运行。双击 `中国象棋.cmd` 后，软件会启动本地服务并自动打开默认浏览器。

启动窗口会一直保留。如果浏览器没有自动打开，窗口中会显示类似 `http://127.0.0.1:端口号/` 的地址，把它复制到浏览器即可。遇到错误时窗口也会保留并显示原因。

退出软件时，点击右上角的“退出”。如果浏览器没有关闭，也可以直接关闭该页面。

## 主要功能

- 完整中国象棋走子规则，包含马腿、炮架、象眼、九宫、过河兵和飞将。
- 将军、绝杀、困毙判断。
- 自由摆放棋子，设置红黑双方行棋权。
- 残局代码导入、复制和内置残局模板。
- Pikafish 顶尖棋力引擎。
- 最大思考时间可调，范围 1 毫秒到 1800000 毫秒（30 分钟），既可直接输入数值，也可拖动进度条。
- 线程数、哈希内存和候选着法数可调。
- 九种 AI 人格，以及可同时叠加的保守、稳健、均衡、进攻、冒险和冲动性格。
- 动态最优解调节器：按指定周期安排“走最优”和“避开引擎首选”的次数、连续段和随机顺序。
- 实时搜索深度、评分、每秒节点、哈希占用和主要变化。
- 悔棋、引擎代走、停止思考和手动切换执子。
- 人机对战与双人同机对战；双人模式可由同一套 Pikafish 持续分析双方局面。
- 可一键翻转棋盘，切换红方视角或黑方视角；翻转后点击落子和走法标记仍保持正确。
- 提示最优解：开启后只在棋盘上标出引擎建议着法的起点、终点和方向，不会替玩家自动落子。
- 一键重置标准开局：无需重新编辑，立即恢复标准 32 子开局并清空当前棋步。
- 只有点击“开始对局”或“引擎走一步”后，软件才会开始计算或走子；载入、导入、识别、重置和切回棋盘都只更新局面，不会自动开局。
- 对弈期间持续分析当前局面；轮到玩家时自动进入无限分析，暂停后可以随时继续。
- 可把当前对局保存为传统中国象棋记谱的 `.txt` 棋谱，也可以导入棋谱继续查看、悔棋和分析。
- 一键导出/导入对局文件：可把整盘对局导出为 JSON，也能导入本软件导出的 JSON，以及 UCI 坐标、ICCS 坐标和传统中文记谱。
- AI 自动复盘：逐手调用 Pikafish 分析，标注好棋、轻微失误和严重漏着，显示进度并可随时取消。
- 复盘对局树：点击任意一手即可跳转到该局面，红箭头标出实战着法、绿箭头标出引擎建议着法，浏览时不会调用引擎。
- 错题本与专项训练：复盘发现的严重漏着会自动进入错题本，可进行抽题训练，走出正解即标记已掌握并保留记录。
- 可选 DeepSeek 语音吐槽：与教练模式是两个独立开关，可持续分析当前局面并逐句朗读，落子后优先点评新一步。
- 教练模式支持“用户主动分析”和“每走一步自动分析”；教练报告也可单独开启语音输出。
- 吐槽与教练语音共用严格串行队列：当前一句完整说完后才播放下一句，新走法会优先更新自动点评。
- 可选 DeepSeek 图片识别残局：选择棋盘照片后自动识别棋子位置、行棋方、双方过河兵卒并载入棋盘。
- 专注视图与全局全屏：可隐藏次要面板专心看棋，也可进入浏览器全屏。
- 低功耗模式：一键把线程降到 2、哈希内存降到 256 MB，并把常驻分析切为一次性提示搜索。
- 一键恢复默认设置：除已保存的 DeepSeek API Key 外，全部设置恢复到初始状态。

## 持续分析

打开软件、载入残局、导入棋谱、使用图片识别或重置标准开局后，软件会停在“等待开始”，不会自动分析，也不会替任何一方走子。只有点击“开始对局”后才会进入正式对弈；点击“引擎走一步”则只会执行当前这一手。

开始对局后，软件会在玩家思考期间保持分析，不断更新深度、评分和主要变化。轮到电脑落子时，电脑按设置的最大思考时间完成本步，走子结束后自动恢复持续分析。

点击“暂停分析”可以释放 CPU；点击“继续分析”后从当前局面恢复。开始新对局、载入局面、悔棋、切换编辑模式或修改性能设置时，分析状态会被安全重置。

## AI 人格、性格叠加与动态配额

“AI 人格”决定搜索深度、候选数量和整体走子水平。基础人格之外，还可以在“叠加性格”中同时选择保守、稳健、均衡、进攻、冒险和冲动，并为每种性格设置 0 到 2 的权重；基础人格始终以权重 1 参与合并。叠加后会共同影响开局偏好、中盘风格和强招、普招、软招、错招的分布。

“动态最优解调节器”用于精确安排多少步走引擎最优、多少步避开引擎首选。可以设置周期步数、走最优次数、避开首选次数、最少连续最优、最多连续避开，以及是否在周期内随机打乱顺序。避开首选时，软件会先从候选池中排除引擎排名第一的走法，再按当前人格和叠加性格选择其他合法着法，不会故意走非法棋。当前步骤的配额会显示在人格状态栏中。

如果局面只有一个合法走法，无法避开首选时软件会自动回退，并显示原因。“超级大师”始终走引擎最优解，不受性格叠加和动态配额影响；切到“超级大师”后相关面板会隐藏。人格、性格权重、走子倾向或调节器发生改变时，配额历史会从新的一步重新开始。自定义设置会保存在本机浏览器中，重新打开软件后自动恢复。

## 保存与导入棋谱

对局中点击“保存棋谱”，软件会把当前对局的起始局面、我方棋色和每一步走法保存为 `.txt` 文件。每一步都采用传统中国象棋记谱，例如“炮二平五”“马8进7”，并在括号内附带精确坐标，例如 `(h2e2)`，保证可以逐步完整还原。

点击“导入棋谱”选择本软件保存的 `.txt` 文件。软件会逐步检查传统记谱与坐标是否一致、走法是否合法，再恢复棋盘和历史记录；如果文件被修改过或两者不一致，会提示原因，并保留当前局面不变。旧版 `.xq` 和 `.json` 棋谱仍可兼容导入。导入后仍可悔棋、继续分析和接着对弈。

## AI 复盘与专项训练

右侧“复盘训练”标签页用于对整盘棋做逐手分析和错题训练，和自由行棋、残局布置、教练模式以及持续思考互斥。进入复盘时软件会自动停止当前无限分析，退出后会按进入前的状态恢复。

“导出对局”会把当前对局的起始局面、完整着法序列（含中文记谱和每一步后的 FEN）保存为 JSON 文件，格式稳定，便于分享和长期存档。“导入对局”可读取该 JSON，也能读取 UCI 坐标、ICCS 坐标以及传统中文纵线记谱；导入时会逐手校验合法性，解析失败会明确提示是第几手非法，不会静默崩溃。软件还内置了一盘用于演示和自检的测试对局，点击“载入测试对局”即可体验完整流程。

点击“开始复盘”后，软件会对每一手执行一次固定 3000 毫秒的分析，对比实战着法与引擎最优着法并计算评分损失，分别标注“好棋”“轻微失误”“严重漏着”。复盘过程会实时显示“分析中 12/46 手”这样的进度和百分比；点击“取消”会立即停止当前分析、清空剩余任务并退出复盘态。复盘期间引擎相关按钮会暂时禁用，复盘全程不会使用无限分析，每一步都严格按“分析当前局面 → 等待结果 → 记录 → 下一手”的顺序执行。遇到将杀或困毙等特殊局面时，软件会优先按杀棋结论判断，不会因为评分数值而漏标。

分析完成后，对局树会按等级着色。点击任意一手可把棋盘跳转到该局面：红色箭头表示实战着法，绿色箭头表示引擎建议着法，相关数据都来自复盘缓存，浏览时不会向引擎发送任何指令。面板会汇总好棋、轻微失误和严重漏着的数量。

复盘发现的严重漏着会写入本机错题本，记录局面、行棋方、实战着法、正解着法、评分损失、来源和掌握状态。“开始错题训练”会随机抽取尚未掌握的题目，把局面加载到棋盘等待你走子。如果走出错题记录的引擎正解，软件会直接判定通过，不消耗任何引擎算力；如果走了别的着法，软件才会重新分析这一步并判断是否仍在可接受范围内。通过后该题会标记为“已掌握”并保留记录，未通过会用中文记谱提示正解、自动进入下一题。训练面板会统计训练次数、通过率和今日新掌握的题数。错题本和训练统计保存在本机浏览器中，不会上传到网络。

复盘和训练过程中软件不会开启无限分析；训练加载的是固定局面快照，不会自动开局，也不会替玩家走子。关闭页面或浏览器标签后，后台只会停止当前搜索并保留引擎进程，避免刷新页面或打开多个标签时误杀正在使用的引擎；需要完全退出时请点击界面右上角的“退出”。

## 双人同机与教练模式

在棋盘上方把对局模式切换到“双人同机”后，红黑双方都由本机用户操作，软件不会替任何一方自动落子。开始对局时，Pikafish 仍可在后台分析当前局面；教练模式与持续思考、提示功能可以同时启用，用于给双方提供评分、建议着法和上一手评价。

语音吐槽和教练语音是两个独立开关，可以只开其中一个，也可以同时开启。两边同时产生语音时不会叠着播放，而是按先后顺序逐句读完；局面发生变化后，尚未朗读的旧自动短评会被新局面的内容替换。

## 提示与重置

点击棋盘上方的“提示最优解”后，软件会在后台持续分析当前局面。轮到玩家行棋时，棋盘会用金色圆圈标出建议起点和终点，并用箭头标出方向；提示只用于显示，不会替玩家落子。关闭提示、落子、悔棋、翻转棋盘、载入局面或重置时会自动清理旧提示。

“重置标准开局”会立即恢复标准 32 子开局、清空全部棋步和最近一步记录，然后停在“等待开始”。它不会删除编辑器中保存的残局代码。

## 本机性能预设

当前机器识别为 Intel Core Ultra 5 225H，软件默认使用：

- 线程数：14
- 哈希内存：自动按可用内存分配（512-2048 MB，内存充足时优先 2048 MB）
- 默认最大思考时间：3000 毫秒

需要更强棋力时，可把最大思考时间调为 30000 或 60000 毫秒。线程和内存设置可在“性能与搜索设置”中修改。

软件会尽量使用多核 CPU。长时间使用 14 线程和 60 秒思考会增加功耗与温度，笔记本使用电池时建议先连接电源。

需要降低功耗或让电脑保持安静时，可打开顶部的“低功耗模式”。该模式会使用 2 线程、256 MB 哈希内存和单路分析，停止玩家回合的常驻思考；提示与教练分析改为一次性有限搜索，不会持续占用 CPU。关闭低功耗模式后会恢复开启前的资源参数。

“专注视图”只隐藏顶部栏和设置面板，保留棋盘与局势分析；“全局全屏”调用浏览器全屏。两者可以独立开启，按 `Esc` 或再次点击按钮即可退出全局全屏。

设置抽屉中的“一键恢复默认设置”会重置难度、人格、思考时间、资源参数、语音、提示和棋盘视角等设置，但会保留已经保存的 DeepSeek API Key。

## DeepSeek 语音吐槽

在“DeepSeek AI 语音吐槽”中填写自己的 DeepSeek API Key，勾选启用后，软件会在当前局面保持分析并持续生成中文短评。语音严格按顺序逐句朗读，当前一句说完后才会开始下一句；出现新走法时，尚未朗读的旧局面短评会被替换，优先点评最新局面，但不会打断正在朗读的那一句。可以试听、停止播报，也可以在浏览器提供多个语音时切换声音。

该功能需要互联网连接和可用的 DeepSeek 账号，可能产生 API 费用。API Key 会保存在本机浏览器中，输入框始终以星号隐藏内容，重新打开软件后会自动恢复，不需要每次重填。Key 不会写入软件源码、日志或安装包，也不会发送到 DeepSeek 之外的地址。DeepSeek 未启用、未填写 Key 或网络不可用时，不影响正常对弈和持续分析。

语音朗读由浏览器及操作系统提供。如果系统没有可用的中文语音，短评仍会显示在页面上。

## 图片识别残局

在“编辑残局”面板中展开“图片识别残局”，填写与语音功能共用的 API Key，选择一张棋盘完整、棋子清楚的图片，再点击“识别并载入”。软件会在浏览器中把图片整理到最长边约 1600 至 2000 像素并轻度增强对比度，再发送给视觉模型。识别时不再假设红方一定在下方，而是先根据红方帅和黑方将的位置判断棋盘方向，必要时自动旋转 180°；模型按原图横竖线交点返回完整 10×9 棋盘矩阵，即使整行没有棋子也会保留该行，随后再按实际文字或圆环颜色区分红黑，并逐枚判断红兵、黑卒是否已经过河。载入后会直接显示“红兵若干枚已过河、黑卒若干枚已过河”，方便核对残局。

默认使用智能仲裁复核：第一轮逐行扫描，第二轮重新查看原图并检查颜色、字形、空行和遗漏；两次结果一致时完成。如果两次结果不同，软件会追加第三次仲裁，避免把上下方向、空行或个别棋子弄错。该模式通常调用视觉模型两次，只有冲突时调用三次。如果接口把输出额度耗在内部推理上、最终正文为空或被截断，软件会按“没有形成结果”处理并重试，不会把内部推理文字误当成棋谱；仍为空时会显示模型名和结束原因。费用和等待时间会相应增加，可在识图区域关闭。

识图接口兼容常见的多种回包格式，包括文本内容数组、`message.text`、`choices[0].text`、`output_text` 和未截断的推理内容字段，不再只读取单一的字符串 `message.content`。

“视觉模型”默认使用 `deepseek-flash`。该模型必须由你的接口账号实际支持图片输入；`deepseek-chat` 和 `deepseek-reasoner` 是文本模型，软件会拒绝用它们识图，避免模型凭空编造棋局。如果视觉接口地址与默认地址不同，可在启动前设置 `DEEPSEEK_VISION_ENDPOINT` 环境变量，指向兼容 OpenAI Chat Completions 格式的视觉接口。图片识别与语音吐槽共用同一个 API Key，保存和隐藏方式相同。

识图请求会主动要求接口返回 JSON。如果模型仍然回复代码围栏、少量解释文字、单引号字段或带尾随逗号的对象，软件会自动清洗并解析；如果第一次没有形成棋局 JSON，软件会自动重新发问，不会立刻把内容当成失败。若模型同时返回了 10×9 棋盘矩阵和可选的棋子列表，两者仅有个别差异时会优先采用完整矩阵，并保留有效的另一份结果作为备选，不再因为一小处矛盾让整张图识别失败。

图片识别可能产生 API 费用，也可能因严重反光、遮挡、棋子被裁掉或棋盘边框不完整而失败。载入后请先检查棋盘；发现个别错误时可直接在编辑器里点击格子修正，或使用残局代码手动调整。

## 残局代码

编辑器使用 Pikafish 兼容的象棋 FEN。示例：

```text
4k4/9/9/9/9/4R4/9/9/9/4K4 b - - 0 1
```

软件也能识别 `H/E` 表示马和象的旧式写法，但复制出的局面会统一写成 Pikafish 标准 `N/B`。

## 运行要求

- Windows x64
- Node.js 20 或更高版本

引擎位于 `engine` 目录。神经网络权重以 `engine/nnue-parts` 中的分卷文件保存，首次启动时会自动校验并合并为 `engine/pikafish.nnue`。不要删除或移动这两个位置，否则棋力引擎不可用。

## 说明

Pikafish 是公开测试中达到超人类水平的中国象棋引擎。实际棋力仍会受到硬件、思考时间、温度、供电、开局局面和引擎设置影响；“超越世界冠军”不是对每一盘棋的形式化保证。
