# -deepseek
本项目是一款基于 Pikafish 引擎的中国象棋智能对弈软件，支持人机对战、双人对战、自由行棋和残局编辑。用户可自定义九档难度、思考时间、搜索深度与 AI 人格，并调整红黑双方及棋盘方向。 软件提供持续分析、教练指导、最优着法提示、绝杀判断和一键恢复标准开局。对局结束后可保存或导入传统中文棋谱、JSON 棋谱，并进行逐手复盘、漏着标注和错题训练。系统还支持残局图片识别、人工纠错、DeepSeek 战术分析与语音吐槽。 项目针对多核电脑优化，兼顾低功耗模式、全屏专注和多项参数一键重置，可打包为无需安装 Node.js 和 Chromium 的 Windows 可执行版本，方便直接运行和传播。
